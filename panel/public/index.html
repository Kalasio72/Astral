Ce que surveille le bouclier

			
    
				
  • Adresses de portes dérobées connues :  — aucune requête ne part.
    • 
				
  • Code téléchargé puis exécuté (RunString / CompileString pendant une réponse HTTP) : bloqué, quelle que soit l'adresse.
    • 
				
  • Fausses textures (.vtf contenant un chargeur de code) : refusées à la compilation.
    • 
				
  • Commandes sensibles depuis Internet (rcon_password, sv_password, ulx, lua_run, sv_cheats) : bloquées.
    • 
				
  • Promotion admin / superadmin hors ULX : bloquée.

Elle ne détecte pas tout : un addon peut tricher sans aucune de ces signatures.
